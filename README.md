# Odin-recipes

## Introduction

Odin Recipes is a pure HTML & CSS website, where recipes are linked to each 
other. This is an opportunity to practice HTML and CSS and build an solid 
foundation of the web backbone.

## See also

This a foundations project, from the full-stack web development curriculum 
[The Odin Project](https://www.theodinproject.com) where the 
main goal is practice HTML & CSS.
